# Datheon Python Programming Internship

**Python Programming Internship – Project Portfolio**

This repository contains three Python projects developed as part of the Datheon Python Programming Internship. Each project focuses on applying Python programming concepts to practical problems while improving problem-solving, logical thinking, and software development skills.

## Projects

### 01. Hangman Game
A command-line word-guessing game developed using Python.

**Key Features**
- Random word selection
- Interactive user input
- Limited attempts
- Tracks correct and incorrect guesses
- Win and lose conditions

**Concepts Practiced:** Variables, loops, conditional statements, strings, lists, functions, and random module.

### 02. Stock Portfolio Tracker
A Python application designed to help users manage and track their stock investments, with integration for retrieving stock market information from the Colombo Stock Exchange (CSE).

**Key Features**
- Add and manage stock holdings
- Record buying prices and quantities
- Retrieve stock market information
- Calculate portfolio-related values
- Store and manage portfolio data

**Technologies:** Python, CSV, Requests, and CSE API.

### 03. Automated File Organizer & Cleanup Utility
A Python utility that automatically organizes files into categorized folders based on their file extensions.

**Key Features**
- Scan a selected directory
- Identify file extensions
- Categorize files automatically
- Create category folders dynamically
- Move files into appropriate folders
- Handle duplicate filenames
- Manage file-operation errors

**Concepts Practiced:** OS module, pathlib, shutil, dictionaries, functions, exception handling, and file management.

## Technologies Used
